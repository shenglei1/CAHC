论文实验绘图说明
================
一、文件位置与可移植性
绘图代码集中在 HyperWave-X/paper_artifacts。
请迁移整个项目时保持 HyperWave-X、HyperComm、TeamComm 三个目录同级。
主实验数据分别读取三个代码目录的 results；消融、超参数和轨迹读取 HyperWave-X/results。
脚本按自身位置寻找输入和输出，不依赖终端当前目录，也不含本机固定路径。
原始实验 CSV 不会被修改。tables_en 和 tables_zh 仅为重新计算的派生统计表。
本目录只生成实验数据图，不重画论文的工程示意图与方法框架图。

二、准备
在 PyCharm 终端激活已安装 numpy、scipy、matplotlib 的 Python 环境。
如缺少依赖：python -m pip install numpy scipy matplotlib
中文字体：Windows 通常自带 Microsoft YaHei；Linux 可安装 Noto Sans CJK SC。
缺少支持的中文字体时脚本会报错提示，不生成乱码图。

三、一键命令（在整个项目根目录运行，Windows PowerShell 和 Ubuntu 均适用）
英文全部：python HyperWave-X/paper_artifacts/plot_all_en.py
中文全部：python HyperWave-X/paper_artifacts/plot_all_zh.py
如果 PyCharm 打开的是 HyperWave-X 目录：
英文全部：python paper_artifacts/plot_all_en.py
中文全部：python paper_artifacts/plot_all_zh.py
两个命令均只绘图，不训练或重新评估模型。

四、输出
英文图片：paper_artifacts/figures_english/
中文图片：paper_artifacts/figures_chinese/
每张图各生成 PDF 和可编辑文本的 SVG；两种语言同名，存放不同目录。
以下路径均相对于 HyperWave-X；算法名称两种语言保持一致。
统计表：paper_artifacts/tables_en/、paper_artifacts/tables_zh/。
统计表字段保留机器可读英文名称，中文翻译只应用于图的显示文字。

五、图片—脚本—命令对应（在 HyperWave-X 目录运行）
1. 主实验（九算法、六场景）：
英文 python paper_artifacts/generate_main_results.py
中文 python paper_artifacts/generate_main_results_zh.py
Figure_1_Task_Completion：任务完成率与五训练种子的95%置信区间。
Figure_3_Reliability_and_Safety：碰撞率与整回合成功率。
Figure_4_Communication_Performance_Pareto：每步逻辑特征传输次数与任务完成率。
Figure_5_Synchronization_Process：缺员率与任务完成率。
保留原绘图脚本的文件名；这些编号与正文排版后的图号不一定相同。

2. 消融、超参数和代表轨迹：
英文 python paper_artifacts/generate_additional_figures.py
中文 python paper_artifacts/generate_additional_figures_zh.py
Figure_9_Ablation_Study：dynamic_overload、scale_20；完整模型及三种消融。
Figure_10_Wave_Iterations：consensus_wide 的波精炼迭代次数敏感性。
Figure_11_Wave_Damping：consensus_wide 的波精炼阻尼敏感性。
上述三图显示任务完成率、能力工作量完成率、同步成功率、缺员率与活跃链路比例，误差棒为已有汇总中的95%区间。
Figure_8_Representative_Episode：Probe 1 seed_20/run1/episode_trace.jsonl 的第一个回合；联盟构建、链路变化、任务执行和首次完成时的注意力。
该轨迹仅用于展示过程，不作为五种子性能比较。

六、证据来源
主实验：TeamComm/results；HyperComm/results/FORMAL_6SCENARIOS；HyperWave-X/results/FORMAL_6SCENARIOS_ORGANIZED_V1。
主实验脚本逐回合读取并按训练种子统计，生成 Source_Data_Inventory.csv 记录来源。
消融：results/ablation_results/ablation_reviewer_metrics_summary.csv。
超参数：results/sensitivity-results/performance_summary.csv。
轨迹：results/PROBES_ORGANIZED_V1/hyperwave_x/lbf_probe_complementary-v0/seed_20/run1/episode_trace.jsonl。
缺失数据不填造；要求的记录缺失时停止并提示。

# CSCWD review artifact

This repository contains the executable implementations used in the study:

- HyperComm
- CAHC
- TeamComm baseline suite

The repository includes the registered scenarios, formal experiment launchers,
evaluation code, two controlled probes, ablation and sensitivity experiments,
cross-configuration evaluation, and figure-generation scripts.

All project paths are relative. Environment setup, experiment commands, and
output locations are documented in the README file of each algorithm suite.
